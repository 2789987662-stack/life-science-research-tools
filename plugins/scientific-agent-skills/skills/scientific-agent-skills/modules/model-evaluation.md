# 统计与模型评价模块

## 数据划分
检查随机划分是否造成同一 gene、guide、target、序列家族或高度相似样本跨集合泄漏。
需要时使用 group / family / gene-level split。

## 指标
回归常看 Pearson、Spearman、MAE、RMSE；
分类常看 ROC-AUC、PR-AUC、F1、校准等。
指标必须与任务目标匹配，不能只挑最有利的一个。

## 基线与消融
- 与原始基线在同一数据、同一划分、同一评价流程比较。
- 新增结构/上下文特征必须通过消融说明增益来源。
- 参数量增加不能自动解释为学到新生物学信息。

## 不确定性
报告重复训练、交叉验证或置信区间，避免单次 seed 结论。
小样本湿实验相关性仅作探索时必须标注。

## 机制边界
模型性能改善 ≠ 已证明机制；
特征重要性 ≠ 因果作用。
